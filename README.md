Task 2 - Exploratory Data Analysis (EDA)

Dataset Used: Titanic Dataset

Tools:
- Python
- Pandas
- Matplotlib
- Seaborn

Steps Performed:
1. Loaded and explored the dataset.
2. Checked missing values.
3. Generated summary statistics.
4. Created histograms and boxplots.
5. Analyzed correlations using a heatmap.
6. Created pairplots for feature relationships.
7. Identified patterns in passenger survival.

Outcome:
Gained insights into feature distributions, correlations, and factors affecting survival.
